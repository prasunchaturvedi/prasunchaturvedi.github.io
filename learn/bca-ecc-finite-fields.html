ECC over prime fields, quadratic residues, EC-ElGamal and RSA vs ECC

Elliptic curves modulo a prime, quadratic residues and Euler's criterion, all points and multiples of a generator on y² = x³ + x + 6 over Z₁₁, an EC-ElGamal round trip, and why ECC beats RSA on key size.

Curves over Zp

Real-number curves suffer rounding; cryptography uses exact arithmetic over a prime field (p > 3). E is the set of (x, y) ∈ Zp × Zp with y2 ≡ x3 + ax + b, 4a3 + 27b2 ≢ 0 (mod p), plus O.

λ = (y2 − y1)(x2 − x1)−1 (addition) or (3x12 + a)(2y1)−1 (doubling), mod p.

x3 = λ2 − x1 − x2; y3 = λ(x1 − x3) − y1; −(x, y) = (x, p − y).

Division becomes multiplication by a modular inverse.

Quadratic residues and Euler’s criterion

z is a quadratic residue mod p if y2 ≡ z has a solution. Exactly (p − 1)/2 non-zero values are residues: mod 11 they are {1, 3, 4, 5, 9}.

Euler: z is a QR ⇔ z(p−1)/2 ≡ 1 (otherwise ≡ −1).

If p ≡ 3 (mod 4): the roots are ±z(p+1)/4 mod p.

Worked curve: y2 = x3 + x + 6 over Z11

4 + 27·36 = 976 ≡ 8 ≢ 0, so non-singular. Since 11 ≡ 3 (mod 4), roots are ±z3.

Multiples of α = (2, 7)

2α: λ = (3·4 + 1)(14)−1 = 2·3−1 = 2·4 = 8; x = 64 − 4 = 60 ≡ 5; y = 8(2 − 5) − 7 = −31 ≡ 2 ⇒ (5, 2).
3α = (5, 2) + (2, 7): λ = 5·(−3)−1 = 5·7 = 35 ≡ 2; x = 4 − 7 ≡ 8; y = 2(5 − 8) − 2 ≡ 3 ⇒ (8, 3).

EC-ElGamal

Worked example

Bob: a = 7, β = 7α = (7, 2). Alice sends Pm = (10, 9) with k = 3: y1 = 3α = (8, 3); 3β = 21α = 8α = (3, 5); y2 = (10, 9) + (3, 5) = (10, 2).
Bob: 7y1 = 21α = (3, 5); subtract by adding (3, 6): (10, 2) + (3, 6) = (10, 9).
