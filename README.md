# prasunchaturvedi.github.io

Static personal website for Prasun Chaturvedi. Plain HTML and one stylesheet (`assets/site.css`); no build step, no JavaScript.

- Pages: `index.html`, `about.html`, `writing.html`, `thanks.html`, `404.html`
- Contact form posts to Web3Forms. The access key in `index.html` is a public Web3Forms form key (safe to expose; it only allows submissions to the owner inbox).
- `drafts/` holds unpublished writing; it is disallowed in `robots.txt` and not linked from the site.
